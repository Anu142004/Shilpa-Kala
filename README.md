# Shilpa Kala – Heritage Sculpture App

> Connecting Ancient Art with the Modern Buyer

## 📖 Overview

**Shilpa Kala** is an Android application built using **Kotlin** and **XML** that helps traditional Indian artisans showcase and sell heritage sculptures through a modern digital platform. The app bridges the gap between skilled craftsmen and global buyers by providing artisans with a professional digital presence.

The platform promotes endangered carving traditions such as the **Hoysala style of Karnataka** while enabling buyers to explore sculptures, view artwork details, and directly connect with artisans.

---

## ✨ Features

### 🏛 Heritage Sculpture Showcase

* Category-wise sculpture gallery
* High-resolution artwork images
* Pricing and artwork descriptions

### 👨‍🎨 Artist Portfolio

* Dedicated artisan profiles
* Showcase signature carving styles
* Display available artworks

### ⏳ Work-in-Progress Timeline

* Displays sculpture creation journey
* Highlights craftsmanship from raw stone to final sculpture

### 💬 WhatsApp Integration

* One-tap enquiry button
* Pre-filled inquiry message for direct communication

### 📚 Heritage Story Section

* Information about:

  * Hoysala style
  * Dravidian architecture
  * Nagara style
* Educational cultural content

### 🎨 Elegant UI/UX

* Terracotta and sandstone-inspired design
* Smooth image loading using Glide
* Pinch-to-zoom sculpture inspection

### 👤 User Profile Management

* Buyer profile details
* Contact and address storage
* Order inquiry support
